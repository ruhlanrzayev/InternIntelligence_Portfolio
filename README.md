# Intern Intelligence Portfolio

A modern and responsive portfolio website developed during my internship. This project showcases my skills, experience, and projects in a clean and interactive way. The goal of this portfolio is to highlight my expertise in front-end development and provide an engaging user experience.

## Features
- Fully responsive design for all devices
- Modern and clean UI/UX design
- Smooth animations and transitions for better interactivity
- Project showcase section with detailed descriptions
- Contact form for easy communication
- Optimized performance and accessibility

## Technologies Used
- **HTML** - Structuring the web pages with semantic elements
- **SCSS** - Enhancing styles with modular and maintainable CSS
- **JavaScript** - Adding interactivity and dynamic content

## Usage
Feel free to explore the portfolio and check out my projects. You can navigate through different sections to learn more about my work and skills. The website is designed to be intuitive and user-friendly, making it easy to browse.

If you have any feedback or suggestions, you can reach out through the contact section.
